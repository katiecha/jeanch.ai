# jeanch.ai

A personal Bald Head Island–inspired sailing gift built with Next.js and React Three Fiber, where you sail a boat around to unlock photo galleries. The 3D scene runs a custom GLSL vertex/fragment ocean shader with real wave geometry, a physics-inspired apparent-wind sail simulation, and fully hand-modeled island landmarks built from Three.js primitives. `@react-three/postprocessing` layers bloom, chromatic aberration, and vignette over the canvas, while `@react-three/drei` handles in-world HTML overlays. Discovery progression follows a graph defined in `lib/graph.ts`, with visited state persisted to `localStorage`.
